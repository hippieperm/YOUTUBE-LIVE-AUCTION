각 버튼이 입찰 채팅을 자동으로 준비합니다. 1·2번은 낙찰을 차단하고, 3번만 하이라이트와 낙찰 안내 입력을 생성해야 합니다.
테스트를 선택하면 결과가 여기에 표시됩니다.

💡 주요 기능 테스트 포인트
1. ⚡ 원클릭 시나리오 8종: 소수점 생략(255=25.5만), 20/30만원 오보정 방지, 동일가 선착순, 회차별 단일 낙찰자 하이라이트 유지, 밑줄 2단계 필수 조건, 다시보기 가드 등 완벽 검증
2. 📐 규격입력: 수고·폭·높이·목대·근장 입력 후 📤 전송 클릭 (가운뎃점 조합 텍스트 입력창 자동 주입, 예: 폭12 · 높이12 · 근장12)
3. 💰 가격입력: 👑 최고가 / ⬆️ 이상(15만이상) / 📋 입력(34만) 즉시 입력 테스트
4. 📁 기타 안내 ▼: 접기/펼치기 토글로 추가 공지문구 버튼 확인
5. 👑 낙찰자 하이라이터: 전용 밑줄 버튼으로 입력한 뒤 전송해야만 골드 하이라이트 & 👑 낙찰 뱃지 자동 부착
6. 실시간 낙찰 자동화: 채팅창 메시지 클릭 시 스마트 감지 / 가상 키패드 팝업
7. 🚫 낙찰 재클릭 취소: 이미 선정된 낙찰자 채팅을 다시 클릭하면 확인창(Alert) 후 하이라이트 해제, 인풋창 비우기, 낙찰 내역 삭제가 즉시 취소 처리됩니다.
8. 📋 낙찰 내역 더미데이터: 5건/15건 더미 데이터를 즉시 생성하여 실시간 배지 증가, 닉네임별 묶음/소계, 엑셀 집계표/경매양식 다운로드를 원클릭으로 테스트할 수 있습니다.
