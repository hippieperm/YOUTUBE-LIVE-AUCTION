# 🔨 YouTube Live 낙찰 자동화 & 안내 패널 스튜디오

YouTube 라이브 경매 방송 진행을 위한 실시간 낙찰 자동화, 8종 맞춤형 안내 버튼, 구분선(밑줄) 기능을 제공하는 Tampermonkey 유저스크립트입니다.

---

## 📂 파일 구성

본 프로젝트는 GitHub에서 깔끔하게 관리할 수 있도록 **단일 유저스크립트 파일 + 설명서**로 구성되어 있습니다.

```
YOUTUBE-LIVE-AUCTION/
├── youtube-live-auction.user.js   # Tampermonkey에 등록하는 단일 스크립트
└── README.md                      # 사용 설명서 및 가이드
```

---

## 🚀 설치 방법

1. 브라우저 확장 프로그램 **Tampermonkey**(또는 Violentmonkey / Greasemonkey)를 설치합니다.
2. Tampermonkey 대시보드에서 **새 스크립트 만들기(+)**를 클릭합니다.
3. [`youtube-live-auction.user.js`](./youtube-live-auction.user.js) 파일의 전체 내용을 복사하여 붙여넣고 저장(`Ctrl+S` 또는 `⌘+S`)합니다.
4. YouTube 라이브 스트리밍/경매 방송 페이지로 이동하면 자동으로 활성화됩니다.

## ✨ 주요 기능 및 조작 방법

### 1. ⚡ 실시간 낙찰 자동화 (조건별 다이렉트 입력 / 스마트 모달)
- **조작 방법**: 채팅창의 **닉네임, 메시지, 또는 채팅 행을 좌클릭** (단축키 없이 원클릭으로 바로 동작)
- **⚡ 1) 숫자가 감지되는 경우 (다이렉트 자동 입력 + 토스트)**:
  - 입찰 채팅(예: `"15만"`, `".5"`, `"15만 5천"`, `"150,000원"`, `"20"`)에서 숫자가 감지되면 **모달을 띄우지 않고**,
  - 유튜브 라이브 채팅 입력창에 즉시 낙찰 문구를 채워주고 포커스합니다:
    > `👉 @닉네임님 {금액}만 낙찰입니다. 감사합니다😄`
  - 채팅창 중앙 상단에 **`⚡ @닉네임님 {금액}만 낙찰 문구 입력 완료!`** 토스트가 즉시 팝업되어 입력 성공 여부를 직관적으로 확인할 수 있습니다.
  - 진행자가 바로 `Enter`를 눌러 신속하게 전송할 수 있습니다.
- **⚡ 2) 숫자가 감지되지 않는 경우 (스마트 모달 팝업)**:
  - 채팅에 숫자가 없는 경우(예: `"저요"`, `"구매합니다"`, 단순 닉네임 클릭 등) 낙찰 처리 모달이 표시됩니다.
  - **🔢 정사각형 가상 키패드**:
    - 시인성과 클릭감이 뛰어난 `1:1 정사각형 비율`의 숫자 키 (`0~9`, `.`)
    - 빠른 증액 버튼 (`+1만`, `+5만`, `+10만`)
    - 지우기 (`⌫`), 전체 삭제 (`C`)
- 모달에서 금액 입력 후 `Enter` 또는 `전송` 버튼을 누르면 채팅창에 자동 입력/전송 후 **전송 완료 토스트**가 표시됩니다.

---

### 2. 🍞 세련된 실시간 플로팅 토스트 알림
- 낙찰 문구 자동 입력, 낙찰 전송 완료, 안내 버튼 클릭, 밑줄 버튼 클릭 등 모든 입력 액션 발생 시 채팅창 상단에 글래스모피즘 스타일의 플로팅 토스트가 부드럽게 나타났다가 사라집니다.

---

### 3. 🎨 안내 버튼 8종 (연관성 순서 배치 & 색상 테마)

채팅창 바로 위에 원클릭으로 정해진 공지 문구를 채팅창에 입력하는 8종 버튼이 배치됩니다.

| 행 | 버튼명 | 포인트 색상 | 주요 내용 |
| :---: | :--- | :--- | :--- |
| **1행 (경매 룰)** | **👤 회원등록** | 파란색 (Blue) | 성함·주소·닉네임 등록 및 변경 시 안내 |
| | **🔨 입찰 안내** | 청록색 (Cyan) | 실시간 딜레이 및 경매장 화면 기준 낙찰 안내 |
| | **💰 호가** | 금색 (Gold) | 금액대별 호가 단위 (10만→1만 / 100만→5만 / 500만→10만) |
| | **🚫 낙찰 취소** | 빨간색 (Red) | 단순변심 취소 불가 및 위약금 30% 안내 |
| **2행 (사후/환경)** | **📦 택배** | 주황색 (Orange) | 수고 50cm 발송 기준 및 기본 택배비(6,000원) 안내 |
| | **🏠 경매장** | 녹색 (Green) | 오프라인 경매장 및 분재원 주소 안내 |
| | **💬 채팅 안내** | 보라색 (Purple) | 유튜브 딜레이 현상 및 재접속 확인 안내 |
| | **❤️ 응원문구** | 핑크색 (Pink) | 좋아요·구독·댓글 응원 문구 |

---

### 4. 🔴 밑줄(구분선) 버튼
- 채팅 입력창 우측에 전용 붉은색 포인트 버튼 배치
- 클릭 시 즉시 `===================` 구분선을 입력창에 채워 경매 품목 간 구분을 용이하게 해줍니다.

---

### 5. 📋 현재 방송 낙찰 내역 관리 & CSV 다운로드 (방송 종료 후에도 항시 조회 가능)
- **실시간 자동 기록**: 낙찰 처리 시 닉네임, 금액, 원문 채팅, 전송 시간 등이 로컬에 안전하게 자동 저장됩니다.
- **방송 종료 후 / 채팅창 숨김 상태 지원**:
  - 라이브 스트리밍이 종료되거나 채팅창이 닫혀 안내 패널이 사라져도, 화면 우측 하단에 **`📋 낙찰 내역 (N건)` 플로팅 버튼**이 자동으로 노출되어 언제든 현재 방송의 낙찰 내역을 열람하고 다운로드할 수 있습니다.
- **다양한 관리 기능**:
  - 📥 **CSV 다운로드**: 엑셀 호환 UTF-8 BOM 인코딩의 CSV 파일로 내보내기
  - 📋 **클립보드 복사**: 정돈된 텍스트 형태로 클립보드에 원클릭 복사
  - 🔄 **4종 정렬**: 최신순 / 오래된순 / 높은가격순 / 낮은가격순
  - 🗑️ **개별 & 전체 삭제**: 불필요한 내역 간편 정리
